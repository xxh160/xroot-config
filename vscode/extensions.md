# VS Code 扩展

| 扩展 | ID | 用途 |
| --- | --- | --- |
| One Dark Pro | `zhuangtongfa.Material-theme` | 个人设置使用的深色主题。 |
| OpenAI Codex | `openai.chatgpt` | 在编辑器里使用 Codex 并查看改动。 |
| VSCodeVim | `vscodevim.vim` | 使用 Vim 模式和键位编辑代码。 |
| Microsoft C/C++ | `ms-vscode.cpptools` | 补全、跳定义、查引用和断点调试。 |
| Makefile Tools | `ms-vscode.makefile-tools` | 在编辑器里选择和构建 Make 目标，依赖本机的 `make`。 |
| GitLens | `eamodio.gitlens` | 查看逐行提交归属、文件历史和提交记录。 |

## 安装

在 VS Code 的扩展面板按 ID 搜索，按需安装。
